# 실기체 시연

## 통합 미션

관제 화면에서 `START → TR → WH` 임무를 시작하고 작업 구역, 컨테이너, 횡단 작업자를 만나는 흐름입니다.

| 순서 | 장면 | 확인할 동작 |
| --- | --- | --- |
| 1 | 관제 화면에서 임무 시작 | 경로 생성·AGV 출발 |
| 2 | 경로 위 작업 구역 | 안전정지·상황 판단·간선 차단·우회 |
| 3 | 경로 밖 컨테이너 | 기존 경로 유지 |
| 4 | 경로 위 컨테이너 | 영향 간선 갱신·대체 경로 생성 |
| 5 | 작업자 횡단 | 정지·대기·통로 해소 후 재출발 |
| 6 | WH 도착 | 미션 완료·관제 상태 갱신 |

2026년 10월 9일 기록: 두 주행 모두 수동 개입 없이 155초, 151초에 완주했습니다.
